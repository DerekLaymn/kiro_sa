usage: typediff [-h] [--out OUT] [--docs DOCS] [--llm LLM]
                [--python-version PYTHON_VERSION] [--no-pyright] [--no-reduce]
                [--audit-rate AUDIT_RATE] [--typeshed TYPESHED]
                {judge,run,loop,seeds,triage,generate,fetch-docs,kb-selftest,calibrate,report} ...

mypy-vs-ty differential bug adjudicator

positional arguments:
  {judge,run,loop,seeds,triage,generate,fetch-docs,kb-selftest,calibrate,report}
    judge               judge pre-computed tool outputs (the 4-input contract)
    run                 run all tools on SRC files and judge
    loop                generation/judging campaign
    seeds               run a seed corpus (recursively), optionally with LLM
                        mutation of hits
    triage              group a run's review queue into patterns
    generate            LLM generation only: write programs to a directory
                        (judge later)
    fetch-docs          download spec/doc corpus for citation verification
    kb-selftest         check KB entries still fire on the installed tool
                        versions
    calibrate           measure false dismissals on real bug reports +
                        documented divergences
    report              draft an upstream issue

options:
  -h, --help            show this help message and exit
  --out OUT
  --docs DOCS
  --llm LLM             override TYPEDIFF_LLM (anthropic:<model> |
                        openai:<model>[@url] | file:<dir> | null)
  --python-version PYTHON_VERSION
  --no-pyright
  --no-reduce
  --audit-rate AUDIT_RATE
  --typeshed TYPESHED   shared typeshed checkout for both checkers (removes
                        stub skew)
