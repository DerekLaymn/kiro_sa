=================== issue astral-sh/ty#4656
title: False negative: Self parameter is not enforced on inherited methods
state: CLOSED  created: 2026-10-03  closed: 2026-10-05T20:28:02Z  author: DerekLaymn
labels: 
body: ### Summary

### Summary

When a method with a `Self`-typed parameter is inherited by a subclass (not overridden), ty does not
apply the subclass binding of `Self` when checking calls. Passing an instance of the base class is
accepted, although ty itself reveals the parameter type as the subclass.

```py
from typing import Self

class Node:
    def add(self, c: Self) -> Self:
        return self

class Leaf(Node):
    pass

x = Leaf()
x.add(Node())  # expected error: `Node` is not assignable to `Leaf`
```

```console
$ ty check test_bug.py --python-version 3.14
All checks passed!
```

**Expected:** an `invalid-argument-type` error. Per PEP 673, `Self` in `Node.add` binds to `Leaf` when
the method is accessed on a `Leaf` instance, so `c` must be a `Leaf`. mypy and pyright both report this
call.

ty's own view of the method agrees that the parameter is `Leaf`:

```py
reveal_type(x.add)  # bound method Leaf.add(c: Leaf) -> Leaf
y: Leaf = Node()    # error[invalid-assignment] Object of type `Node` is not assignable to `Leaf`
```

If `Leaf` overrides `add` with the same signature, ty does report the call:

```
error[invalid-argument-type] Argument to bound method `Leaf.add` is incorrect: Argument type `Node`
does not satisfy upper bound `Leaf` of type variable `Self`
```

The same false negative occurs for other forms of the inherited method (all accepted without error):

```py
class Node:
    def add_all(self, cs: list[Self]) -> Self: return self
class Leaf(Node): pass
Leaf().add_all([Node()])

Leaf().add(c=Node())          # keyword argument
Leaf.add(Leaf(), Node())      # unbound call

class Box[T]:
    def merge(self, other: Self) -> Self: return self
class IntBox(Box[int]): pass
IntBox().merge(Box[int]())
```

Possibly related: #4387.

Playground: <https://play.ty.dev/0c7b2062-683c-4788-b0cb-132118785d27>
