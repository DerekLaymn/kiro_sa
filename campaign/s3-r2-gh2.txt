#11342 CLOSED COMPLETED closed=2022-04-07T21:51:48Z False negative: "Name not defined" error should be reported when variable is declared with a type annotation but not assigned to before use
**Bug Report**

```python
x: int
print(x)
```

Mypy does not report an error for the code above or for this code:

```
print(x)
x = 0
```

But reports:
error: Name "x" is not defined

for:

```
print(x)
```

At runtime Python reports:
NameError: name 'x' is not defined

in all three cases.

**Expected Behavior**

Mypy should report `Name "x" is not defined` in all three cases.
