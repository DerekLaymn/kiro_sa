# Seeds

These are hand-written seed programs, one feature area per folder. The folder name sets the area
used in `typediff` statistics.

Each program:
- targets a typing feature ty claims to support;
- runs under **CPython 3.13**, so the runtime oracle works;
- calls everything it defines;
- marks lines a spec-conformant checker should reject with `# expect-error: …`. Lines that would
  crash at runtime are wrapped in `try/except`. Two seeds raise on purpose (marked in their
  headers) to give typediff a runtime oracle.

```bash
TYPEDIFF_LLM=null typediff --python-version 3.13 seeds seeds/          # judge all seeds (~1 min)
typediff --llm ... --python-version 3.13 generate --from-seeds seeds/self_classmethods --n 5 --out-dir runs/gen
python scripts/harvest_seeds.py                                         # + 4,849 programs from upstream tests
```

`seeds/harvested/` is generated by `scripts/harvest_seeds.py` and is not committed.
